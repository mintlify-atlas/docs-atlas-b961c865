## Welcome to MoviePlay API

MoviePlay is a production-ready REST API built with Spring Boot that manages a comprehensive movie catalog. It combines modern backend development practices with AI-powered recommendations to deliver a robust and intelligent movie management platform.

The API is live and fully documented with interactive Swagger UI:

## Technology stack

MoviePlay leverages modern Java and Spring Boot technologies:

- **Java 21** - Latest LTS version with modern language features
- **Spring Boot 4** - Industry-standard framework for production applications
- **Spring Data JPA** - Simplified database access and entity management
- **PostgreSQL** - Reliable relational database for production workloads
- **MapStruct** - Type-safe DTO mapping with compile-time generation
- **LangChain4j** - AI integration framework for intelligent recommendations
- **Springdoc OpenAPI** - Automatic API documentation and testing UI
- **Gradle** - Modern build automation and dependency management
- **Docker** - Container platform for consistent deployments

## Design principles

MoviePlay demonstrates these architectural principles:

- **Domain-driven design** - Clear business logic separated from infrastructure
- **Layered architecture** - Controller, Service, Repository, and Entity layers
- **Dependency inversion** - Abstractions (interfaces) decouple business logic from persistence
- **Single responsibility** - Each component has a focused, well-defined purpose
- **Open for extension** - New features can be added without modifying existing code

<Note>
  The API follows REST best practices with proper HTTP methods, status codes, and resource-based URLs.
</Note>
