## Get up and running

This guide will help you run the MoviePlay API on your local machine and make your first API calls.

<Note>
  **Prerequisites:** Java 21, Docker (optional), and a terminal/command prompt
</Note>

## Run with Docker Compose (recommended)

The fastest way to get started is using Docker Compose, which sets up both the API and PostgreSQL database:

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/your-repo/movieplay.git
    cd movieplay
    ```
  </Step>

  <Step title="Start the services">
    ```bash
    docker-compose up -d
    ```
    
    This starts PostgreSQL on port 5432 with the following configuration:
    - Database: `movie_play_db`
    - Username: `psantana`
    - Password: `password`
  </Step>

  <Step title="Build and run the application">
    ```bash
    ./gradlew bootRun
    ```
    
    The API will start on `http://localhost:8080/movie-play/api`
  </Step>

  <Step title="Verify it's running">
    Open your browser and navigate to the Swagger UI:
    ```
    http://localhost:8080/movie-play/api/swagger-ui/index.html
    ```
  </Step>
</Steps>

## Run with local PostgreSQL

If you prefer to use an existing PostgreSQL installation:

<Steps>
  <Step title="Create the database">
    ```sql
    CREATE DATABASE movie_play_db;
    CREATE USER psantana WITH PASSWORD 'password';
    GRANT ALL PRIVILEGES ON DATABASE movie_play_db TO psantana;
    ```
  </Step>

  <Step title="Configure the application">
    The default configuration in `src/main/resources/application-dev.properties` should work with the above setup.
    
    If you need different credentials, update the properties:
    ```properties
    spring.datasource.url=jdbc:postgresql://localhost:5432/movie_play_db
    spring.datasource.username=your_username
    spring.datasource.password=your_password
    ```
  </Step>

  <Step title="Build the application">
    ```bash
    ./gradlew build
    ```
  </Step>

  <Step title="Run the application">
    ```bash
    java -jar build/libs/movieplay-1.0.0.jar
    ```
  </Step>
</Steps>

## Run with Docker

You can also build and run the entire application as a Docker container:

<Steps>
  <Step title="Build the Docker image">
    ```bash
    docker build -t movieplay .
    ```
    
    The Dockerfile uses a multi-stage build:
    - Stage 1: Compiles the application with Gradle 9.3.0 and JDK 21
    - Stage 2: Creates a minimal runtime image with just the JAR file
  </Step>

  <Step title="Run the container">
    ```bash
    docker run -p 8080:8080 \
      -e SPRING_DATASOURCE_URL=jdbc:postgresql://host.docker.internal:5432/movie_play_db \
      -e SPRING_DATASOURCE_USERNAME=psantana \
      -e SPRING_DATASOURCE_PASSWORD=password \
      movieplay
    ```
    
    <Note>
      Use `host.docker.internal` to connect to PostgreSQL running on your host machine
    </Note>
  </Step>
</Steps>

## Make your first API call

Once the API is running, let's create and retrieve a movie:

<Steps>
  <Step title="Create a movie">
    ```bash
    curl -X POST http://localhost:8080/movie-play/api/movies/save \
      -H "Content-Type: application/json" \
      -d '{
        "title": "The Matrix",
        "duration": 136,
        "genre": "SCI_FI",
        "releaseDate": "1999-03-31",
        "rating": 8.7,
        "status": true
      }'
    ```
    
    **Response:**
    ```json
    {
      "title": "The Matrix",
      "duration": 136,
      "genre": "SCI_FI",
      "releaseDate": "1999-03-31",
      "rating": 8.7,
      "status": true
    }
    ```
  </Step>

  <Step title="Get all movies">
    ```bash
    curl http://localhost:8080/movie-play/api/movies/all
    ```
    
    **Response:**
    ```json
    [
      {
        "title": "The Matrix",
        "duration": 136,
        "genre": "SCI_FI",
        "releaseDate": "1999-03-31",
        "rating": 8.7,
        "status": true
      }
    ]
    ```
  </Step>

  <Step title="Get AI recommendations">
    ```bash
    curl -X POST http://localhost:8080/movie-play/api/movies/suggest \
      -H "Content-Type: application/json" \
      -d '{
        "userPreferences": "I love sci-fi movies with mind-bending plots"
      }'
    ```
    
    <Warning>
      AI recommendations require an OpenAI API key configured in your environment
    </Warning>
  </Step>
</Steps>

## Available endpoints

Here are the main endpoints you can use:

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/movies/all` | Get all movies in the catalog |
| `GET` | `/movies/{id}` | Get a specific movie by ID |
| `POST` | `/movies/save` | Create a new movie |
| `PUT` | `/movies/{id}` | Update an existing movie |
| `DELETE` | `/movies/delete/{id}` | Delete a movie |
| `POST` | `/movies/suggest` | Get AI-powered movie recommendations |

## Available genres

When creating or updating movies, use one of these genre values:

- `ACTION`
- `COMEDY`
- `DRAMA`
- `ANIMATED`
- `HORROR`
- `SCI_FI`

<Note>
  Genre values are case-sensitive and must match exactly as shown above.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Database connection failed">
    Make sure PostgreSQL is running and accessible:
    ```bash
    docker ps  # Check if postgres container is running
    psql -h localhost -U psantana -d movie_play_db  # Test connection
    ```
  </Accordion>

  <Accordion title="Port 8080 already in use">
    Either stop the other application using port 8080, or change the port in `application.properties`:
    ```properties
    server.port=8081
    ```
  </Accordion>

  <Accordion title="Gradle build fails">
    Make sure you're using Java 21:
    ```bash
    java -version  # Should show version 21
    ```
    
    If you have multiple Java versions, set `JAVA_HOME` to Java 21.
  </Accordion>
</AccordionGroup>
