## Endpoint

```
POST /movie-play/api/movies/suggest
```

## Description

Generates personalized movie recommendations based on user preferences using AI-powered suggestion engine. Provide your preferences in natural language and receive tailored movie suggestions.

## Request Body

<ParamField body="userPreferences" type="string" required>
  Natural language description of user's movie preferences
  
  Describe what kind of movies you enjoy, preferred genres, themes, moods, or specific characteristics you're looking for.
  
  Example: `"I love sci-fi movies with time travel themes and mind-bending plots"`
</ParamField>

## Response

<ResponseField name="suggestions" type="string">
  AI-generated movie suggestions as a text response based on the provided user preferences
</ResponseField>

## Status Codes

| Code | Description |
|------|-------------|
| 200  | Success - AI suggestions generated successfully |
| 400  | Bad Request - Invalid request body |

## Example Request

```bash cURL
curl -X POST https://movieplay-424k.onrender.com/movie-play/api/movies/suggest \
  -H "Content-Type: application/json" \
  -d '{
    "userPreferences": "I love sci-fi movies with time travel themes and mind-bending plots"
  }'
```
